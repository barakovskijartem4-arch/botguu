# Помощник студента — Telegram-бот

Бот для студентов: расписание и домашние задания по группам.
Сейчас умеет отвечать на `/start`.

Стек: Python, [aiogram 3](https://docs.aiogram.dev/), SQLite. Хостинг: [Amvera](https://amvera.ru/).

## Как это работает

- Код живёт в GitHub. После мержа pull request'а в `main` Amvera сама забирает
  код, пересобирает и перезапускает бота.
- База данных — файл SQLite `/data/bot.db` в постоянном хранилище Amvera.
  Папка `/data` **не стирается** при пересборке, а файл базы не хранится в git,
  поэтому мержи данные не затирают.
- Токен бота хранится только в секретах Amvera (и в `.env` при локальном запуске).

## Настройка Amvera (один раз)

### 1. Токен бота

Если бота ещё нет: напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.

### 2. Проект на Amvera

1. Войдите в [amvera.ru](https://amvera.ru/) → **Создать проект** → тип «Приложение».
2. Тариф: для начала хватит «Пробного».
3. Способ загрузки кода — через Git (сам код подключим на шаге 4).
4. Настройки сборки менять не нужно: они берутся из файла `amvera.yml` в репозитории.

### 3. Секрет с токеном

В проекте откройте **Переменные** → **Добавить переменные или секрет**:

| Название        | Значение                         | Обязательно |
|-----------------|----------------------------------|-------------|
| `BOT_TOKEN`     | токен от @BotFather (как секрет) | да          |
| `TELEGRAM_PROXY`| адрес прокси, например `http://host:port` или `socks5://host:port` | только если Telegram недоступен напрямую |
| `PYTHONUNBUFFERED` | `1` (чтобы логи появлялись сразу) | желательно |

После изменения переменных перезапустите проект.

### 4. Автодеплой из GitHub

1. **Токен GitHub.** GitHub → Settings → Developer settings → Personal access tokens →
   **Tokens (classic)** → Generate new token. Отметьте право `repo`, срок — без истечения.
   Скопируйте токен.
2. **В Amvera:** проект → вкладка **Репозиторий** → подключение GitHub:
   - событие: **Push**;
   - ветка: **main**;
   - придумайте и введите **секрет** (любая длинная строка), вставьте токен GitHub;
   - скопируйте показанный **URL** → **Применить**.
3. **В GitHub:** репозиторий `botguu` → Settings → **Webhooks** → **Add webhook**:
   - Payload URL — URL из Amvera;
   - Content type — `application/json`;
   - Secret — тот же секрет, что в Amvera;
   - событие — **Just the push event** → **Add webhook**.

Готово: каждый мерж в `main` запускает пересборку на Amvera.
Подробнее — в [документации Amvera](https://docs.amvera.ru/applications/git/webhooks.html).

### 5. Проверка

1. Смёрджите pull request в `main` и подождите, пока статус проекта станет
   «Успешно развернуто» (логи могут появляться с задержкой в несколько минут).
2. В логах должна быть строка `База данных: /data/bot.db`.
3. Напишите боту `/start`.

Если бот молчит, а в логах ошибки подключения к Telegram — задайте `TELEGRAM_PROXY`
и перезапустите проект.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и впишите BOT_TOKEN
python bot.py
```

Локально база создаётся в файле `bot.db` в папке проекта.

Не запускайте бота локально, пока он работает на Amvera с тем же токеном:
Telegram позволяет только одному экземпляру получать сообщения.
